# 🐣 우당탕탕 코테 정복기 (feat. C++)

> 자료구조와 알고리즘, 하나씩 부딪히고 깨지면서 정리해나가는 나의 좌충우돌 코딩테스트 여정 기록소입니다.

C++로 코테를 준비하기로 결심한 이후, 자료구조부터 차근차근 다지고 있습니다.

## 📌 이 저장소는

- **언어**: C++
- **목표**: 코딩테스트 통과를 위한 자료구조 & 알고리즘 개념 정리 + 문제 풀이
- **방식**: 개념 학습 → 직접 구현/정리 → 관련 문제 풀이 → 회고
- **참고 커리큘럼**: [GeeksforGeeks DSA Tutorial](https://www.geeksforgeeks.org/dsa/dsa-tutorial-learn-data-structures-and-algorithms/)의 "Step by Step Learning" 순서를 따릅니다.
